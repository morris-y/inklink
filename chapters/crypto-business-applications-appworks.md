## 未來可能的重要商業應用

基於以上的觀察，我認為下面五個領域可能成為 crypto 的重要商業應用。

### 1. 穩定幣之上的企業金融服務

穩定幣支付的下一步，很自然會延伸到企業金融。有了支付紀錄，就能做貿易融資。鏈上資料任何人都能驗證，所以可以做自動化的出帳和對帳系統。甚至可以讓 agent 幫你做審計，做完發出一個 proof，證明帳目和鏈上資料相符。

這裡我要補一個我自己的保留：光是在支付這一端採用 crypto，不會是真正的用例。PayPal 已經推出自己的穩定幣，Mastercard、Visa 也進場了。我一直在重新想的問題是：人們一開始為什麼想把東西放上鏈？鏈上的解法到底解決了什麼？企業金融有意思，是因為它用到了鏈上資料「全局可驗證」這個特性，不只是換一種付款方式。

### 2. DeFAI

DeFAI 指的是 DeFi 加上 AI。可組合性是區塊鏈最常被提到的價值之一，體現在各種收益和套利策略裡。AI 可以降低這些組合的複雜度。反過來，DeFi 的可組合性也讓 agent 有更大的發揮空間，因為它不需要等中心化應用開放 API，就能組出更多客製化的策略。

換個角度說，AI 讓 DeFi 找到一個新的分發管道。我期待看到個人的量化交易 AI 助手，幫一般人優化自己的資產配置。

### 3. Agent 評測系統

怎麼驗證一個 agent 的工作品質？區塊鏈的公開帳本特性，可能讓它成為評判 AI 系統表現的理想平台。agent 做了什麼交易、結果如何，都留在鏈上，誰都能查。

### 4. 擁有錢包的 agent

agent 有了錢包、有了資產所有權之後，可以做什麼？

- 自主分配資本來達成目標，例如買更多算力，或僱用其他 agent。
- 多個 agent 可以組織起來合作，一起出資完成特定任務。
- 有錢包的 agent 會發展出「預算」的概念，學著用最低成本完成任務。

我的另一個觀察是：agent 跟支付結合，重點反而不是開發 agent，而是開發願意接受鏈上金流的基礎設施。只做 agent，會有無處施力的感覺。

### 5. 還有什麼資產適合代幣化？注意力

我覺得注意力和影響力的代幣化很有意思，因為注意力是終極的稀缺資源。社群媒體、遊戲、娛樂產業，最後都在搶使用者的注意力。

任何新資產發行，最難的一步都是定價。Kaito 嘗試用內容品質替注意力定價。它的定價演算法細節目前不公開，但關鍵在於，它的商業模式必須建立在內容品質演算法上：品質評估越準，賺得越多，形成正向循環。做不到這點，就會像傳統媒體一樣，只靠流量賺錢、不靠內容品質，最後被訂閱制取代。

Google 搜尋是最好的例子：搜尋結果的品質越高，關鍵字廣告就越賺錢。

當時還有一個讓我印象深刻的數字：KAITO 空投之後，有 35% 的代幣被質押。在當時的市場，大家願意相信一個專案的長期願景，是很少見的。

## 小結

這五個方向有一個共同點：它們用到的是區塊鏈本身的特性，像鏈上資料可驗證、公開帳本、可組合性、可程式化的資產所有權，而不是把現有流程換成用幣支付。這也是我一直在重新想的問題：一件事為什麼一定要放在鏈上？
